# HTML & CSS Practice

A small collection of introductory front-end exercises covering Emmet, basic HTML structure, CSS styling, and Flexbox layouts.

## Files

- `index.html` — starting page.
- `emmet.html` — Emmet and HTML markup practice.
- `flexbox.html` — Flexbox layout exercises.
- `style/styles.css` — styles used by the pages.

## Run locally

Open any HTML file in a browser, or use the VS Code Live Server extension. Keep the relative folder structure intact so styles load correctly.

## Status

This repository is a learning exercise archive, not a production website.
